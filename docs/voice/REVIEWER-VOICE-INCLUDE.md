# Matchstick original voice · reviewer instruction

Read the complete VOICE-PROFILE.md and its original calibration examples. Independently check usefulness, freshness and evidence, then judge the reading experience. Accurate but stiff document-summary prose must receive REVISE, with specific repairs in the existing failures/revisionInstructions fields. Use the existing schema; do not create another output format or an extra review stage.

A voice pass needs a practical human viewpoint, a clear useful lead, a small number of details that earn their space, ordinary language and natural rhythm. If there is humor, it should emerge from this subject’s mechanism rather than a generic closing wisecrack. A warm or sober story can pass without a joke. Shorter is not automatically better; cutting the paragraphs without finding the human story is not a voice pass.

Flag specific defects: official-process lead, miniature agenda, jargon, duplicate deck/opening, research narration, unnecessary caveats, canned quip, inappropriate target or unsupported implication. Give an edit the writer can execute: which fact to lead with, which distinction to explain, which detail to cut. “Make it funnier” is insufficient. Do not demand a particular joke or append your own factual invention.

Check implied events, costs, status, motives, timing and reactions in any flourish. Clearly figurative comparisons do not need verbatim source support, but their underlying facts and apparent factual implications do. Reject invented scenes/quotes, copied author routines, partisan conclusions and unverified allegations. Evidence-based institutional scrutiny is allowed; neutral prose need not be bland. Protect people experiencing harm; safety instructions stay sober and literal. Fixtures are never local evidence.

Keep existing canonical output and release gates. A useful factual draft with correctable style needs REVISE; missing core evidence needs HOLD. Any revised text returns through fresh independent factual review. Do not pass lifeless copy simply because it contains no factual errors.
